# Adversarial attacks on the highway conjecture

Tries to break the conjecture (or delay the highway as long as possible) with four attacks, all
using `antsim.c` (same conventions and certification rule as `research/exhaustive/exhaust.c`,
cap 50,000,000 steps, grid 8192):

| attack | script | what | runs |
|---|---|---|---|
| A | `attack_a.py` | small blocks (1x1..3x3, lines, L) placed on or beside the empty-grid highway; 1,512 placements, 616 hit the road, all 616 rebuilt a highway | 1,512 |
| B | `attack_b.py` | (1+lambda) evolutionary search for the longest onset in the 12x12 box; two main runs of 10,000 evaluations, two wall-clock-limited extended runs | 3,483,028 |
| C | `attack_c.py` | 203 named (202 distinct) structured seeds: squares, rings, lines, crosses, ... | 203 |
| D | `attack_d.py` | greedy chaining of 2x2 blocks on successive highways; four blocks (16 cells) give onset 259,274 | 146 |

Results: `research/results/adversarial.json`, `research/results/adversarial_best.json`.

## Reproduce

    sh research/adversarial/run_all.sh          # A, C, D and the two main GA runs: 21,861 deterministic runs, ~30 s + GA
    python3 research/adversarial/count_evidence.py   # recount the archived extended GA logs and re-simulate 200 random rows

`run_all.sh` regenerates attacks A, C, D and the two main GA runs exactly. The two extended GA
runs (seeds 11 and 12, lambda 8, budget 10^8, wall-clock limited) were stopped by the session
harness after about 270 s each and cannot be regenerated to the same count on another machine;
their complete evaluation logs are archived instead:

| file | rows |
|---|---|
| `evidence/attack_b_ext_seed11.csv.gz` (+ `_summary.json`) | 1,742,445 evaluations |
| `evidence/attack_b_ext_seed12.csv.gz` (+ `_summary.json`) | 1,720,583 evaluations |
| `evidence/attack_b_main_seed{1,2}.csv.gz` (+ `_summary.json`) | 10,000 each (also regenerated by `run_all.sh`) |

Each row is `eval,restart,onset,outcome,nblack,genome_hex` (genome = 144 bits, cell i = bit i of
the 12x12 box with x,y in -6..5). `count_evidence.py` recounts every archived run (3,483,028
evaluations, 0 non-certified, 2,676,229 distinct genomes, best onset 233,232), checks the
summaries against the rows, and re-simulates a random sample of rows with `antsim`.
`aggregate_b.py` reads the archived logs when no fresh `out/attack_b_*.csv` exists, so
`research/results/adversarial_best.json` and the 3,484,889-run total of `adversarial.json` can be
recomputed from the repository alone. Before these logs were committed the total could not be
audited from the repository (adversarial review on the pull request).

Note on counting: 3,484,889 is a number of simulation runs; the GA re-evaluated 806,799 genomes,
so the number of distinct configurations is about 2,677,946.
